📋
How to get your Azure OpenAI credentials
  1. Go to portal.azure.com → search "Azure OpenAI"
  2. Select your company's OpenAI resource → Keys and Endpoint
  3. Copy the Endpoint URL and KEY 1
  4. Go to Azure AI Studio (ai.azure.com) → Deployments
  5. Note your deployment name (usually gpt-4o or gpt-4)
  6. If you don't have access, raise a request to your IT/Cloud team — they may share a shared key
